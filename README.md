# Valentine Interactive Web App

An interactive and playful "Will You Be My Valentine?" web experience with cursor avoidance, animations, and celebratory interactions.

## Features
- **Fleeing Button Dynamics**: Physics-like cursor avoidance on rejection button.
- **Heart Falling Animations**: Custom CSS and JS particle system.
- **Mobile Responsive**: Fully responsive for touch devices.
- **Security Hardening**: Secure HTTP headers and directory listing protection.

## Structure
- `public_html/` - Web root containing the application.
- `public_html/.htaccess` - Production security rules and headers.
